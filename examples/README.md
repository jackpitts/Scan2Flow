# Command examples

See [commands.md](commands.md) for photo, video, LiDAR and CFD-domain planning examples.
All processing commands use `--dry-run`. Input paths are illustrative and no media,
pretrained weights or generated CAD are supplied.

A dry-run checks command arguments only. It does not read files, load a model or
produce geometry. See the [CLI reference](../docs/CLI_REFERENCE.md) for all options.
